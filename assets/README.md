# Brand Asset Source

The 512×512 extension icon master is `skeptical-wombat-icon-master.png`. It was generated on August 12, 2026 from the repository's existing Skeptical Wombat reference artwork, with these production constraints:

- front-facing rust-orange wombat with crossed arms and a skeptical expression;
- cyan browser-tab motif;
- transparent background, no text, no watermark;
- crisp, high-contrast silhouette that remains recognizable at toolbar sizes.

The Chrome icon exports in `../icons/` use size-specific crops. The 128 px export keeps the artwork inside an approximately 96 px safe area with transparent padding, following Chrome extension icon guidance. Smaller exports emphasize the face for legibility.

The promotional art in `../store-assets/` was generated from the same visual direction. Store-ready exports add exact project typography programmatically; the generated artwork itself contains no text.

These assets are original project artwork and are distributed under the repository's MIT license.
