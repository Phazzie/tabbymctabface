# Support

Before filing a report:

1. update to the latest release;
2. reload the extension at `chrome://extensions`;
3. confirm the problem in a normal Chrome profile; and
4. check the [user guide](./docs/USER_GUIDE.md) and existing [issues](https://github.com/Phazzie/tabbymctabface/issues).

For a bug, open a [GitHub issue](https://github.com/Phazzie/tabbymctabface/issues/new) with your Chrome version, extension version, operating system, steps to reproduce, and any extension service-worker or popup console errors. Remove private URLs and tab titles from screenshots and logs.

Use the private process in [SECURITY.md](./SECURITY.md) for security reports.
