# Security Policy

## Supported version

Security fixes are applied to the latest release and the default branch.

## Report a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private [security-advisory form](https://github.com/Phazzie/tabbymctabface/security/advisories/new) and include:

- the affected version or commit;
- reproducible steps and expected impact;
- any proof of concept that is safe to share; and
- a suggested remediation, if you have one.

You should receive an acknowledgement within seven days. Please allow time for a coordinated fix before public disclosure.

TabbyMcTabface has no backend and sends no browsing data over the network. Its highest-risk boundaries are Chrome permissions, extension messages, and local storage; reports involving those seams are especially useful.
