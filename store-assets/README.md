# Chrome Web Store Assets

This directory contains optimized, upload-ready artwork for the store listing.

| File | Purpose | Dimensions |
| --- | --- | --- |
| `promo-small-440x280.png` | Required small promotional tile | 440×280 |
| `marquee-1400x560.png` | Optional marquee promotional image | 1400×560 |
| `screenshot-popup-1280x800.png` | Required product screenshot | 1280×800 |

Screenshots must show the real packaged popup and must be regenerated after a visible UI change. Do not place simulated controls or unimplemented claims into store artwork.
