# Screenshots for Chrome Web Store

## Quick Start

1. **Open `templates/all-screenshots.html` in your browser**
2. **Set browser window to 1280x800** (use DevTools Device Mode)
3. **Capture each screenshot** using your system tool
4. **Save as PNG files**: 01-features.png, 02-shortcuts.png, etc.

## Files

- `templates/all-screenshots.html` - All 5 screenshots in one page for easy capture
- Generated PNG files will go here (not committed to git)

## Automated Generation (Optional)

If Playwright works in your environment:

```bash
npm install
npm run screenshots
```

This will automatically generate all screenshots.
